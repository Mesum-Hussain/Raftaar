# Raftaar: state for the next agent

Dense on purpose. Read this before touching code; verify symbols with grep, line numbers are not kept here.

## What this is
- Code editor + terminal in hand-written x86-64 assembly (GNU as, Intel syntax). Static, no libc, no dynamic linker; ~2.3 MB debug, ~0.8 MB release.
- Fork of rhun 0.17.11 (github.com/vshvedov/rhun, MIT). `LICENSE` keeps the upstream notice; README has the fork line. Nothing goes upstream.
- Repo: github.com/Mesum-Hussain/Raftaar, branch `main`. Old rhun history: `~/Code/rhun.git-backup` (not in this repo).
- Owner runs it from the repo root (`./raftaar`) and from `~/.local/bin/raftaar` (`tools/install.sh`).

## Build, run, test
- `./build.sh` -> `build/raftaar` + copy `./raftaar`. `./build.sh test` also links `tests/*.s`. `./build.sh release` strips. Always rebuild after edits.
- `sh tests/run.sh`: whole suite, ~6 min, exit 0 is the bar. `tests/ui.sh update` rewrites `tests/data/*.ui.expected`.
- Headless driver: `raftaar DIR --headless WxH --scale 1 --script F.rsc`. Commands in `src/app/control.s` (`cmd NAME`, `key`, `type`, `click x y [right|middle]`, `move`, `resize`, `shot F.ppm`, `wait ms`, `wait-git`, `print-tabs|state|panels|scm|menu|tip|git|term`, `open`, `quit`). `cmd NAME` takes palette names from `src/app/keys.s`. Screenshots: `magick f.ppm f.png`.
- Give tests their own `HOME`, `XDG_CONFIG_HOME`, `XDG_STATE_HOME`.
- Known red, not ours: 2 `wget` 503 cases in `tests/install-download.py` (system wget is wget2; same on untouched rhun; not in `run.sh`).
- macOS/Windows are untested here. macOS = `tools/arm64.py` translating the x86 sources; it rejects the `.irp` in `src/raftaar.inc` (TAB_COPY), so the Mac build is likely broken since before the fork. Windows: `src/win/`, `tools/build-windows.py`.
- After code edits: `graphify update .` (owner's AGENTS.md rule; `graphify-out/` is tracked).

## Layout
- `src/raftaar.inc` macros, structs, `TAB_*`, `IC_*`, `MI_*`. `src/main.s` args + `open_initial`. `src/loop.s`, `sys.s`, `proc.s`, `mem.s`, `lib.s`.
- `src/app/app.s` (6k lines): render, title bar, tabs, dialogs, welcome page, commands. `panes.s` splits. `explorer.s` tree + context menus. `settings.s` page, `config.s` schema (`SETTING` rows drive page, file and tests). `keys.s` command table. `gitview.s` history tab, `scm.s` source-control panel. `termview.s`/`term.s` terminals. `editor.s`, `vim.s`, `palette.s`, `update.s`, `desktop.s`, `closed.s`, `session.s`.
- `src/plat/` wayland, x11, headless. `src/gfx/` canvas, font, icons (`icondata.s` is generated by `tools/icons.py`). `src/ui/ui.s` widgets.
- `runtime/` themes (`raftaar-dark|light`), syntax. `assets/icons/raftaar.svg` is the icon source; `tools/app-icons.py` renders PNG + icns (needs `magick`).

## Idioms that bite
- `FN name` global; `PROLOGUE [frame]`/`EPILOGUE` save rbx, r12-r15; args rdi rsi rdx rcx r8 r9, 7th+ pushed (push twice to keep alignment). Local numeric labels: check the nearest `Nf`/`Nb` before adding one.
- Metrics: `M reg, MI_n` or `[rip + g_mt + 4*MI_n]` are scaled px. `sc(points)` scales by display; `fz(points)` scales by UI font. `COLOR reg, T_x` theme color.
- Text: `text_width(face, ptr, len)`, `ui_text_v`, `ui_text_c`, faces `g_face_ui|small|mini|huge`.
- Buttons: `ui_btn(id,x,y,w,h)` -> `UB_HOVER|PRESS|CLICK|RPRESS|DOUBLE`. Menus: `ctx_menu_open(items,x,y)`, items are (label, fn) quads ending 0. Confirm: `app_confirm(q, line, button, fn)`.
- Hard-coded string lengths exist (`RAFTAAR_LEN` in app.s, WM_CLASS length in `plat/x11.s`); a rename must fix them.
- Keep to instruction forms already in the tree (arm64 translator). New ioctl numbers need a case in `src/mac/linux.s` `sys_ioctl`.
- Comments are terse, lower-case, say why. Match them.

## Changes since rhun 0.17.11 (owner's requests, all shipped)
Git panel (`scm.s`, `gitview.s`)
- `center_label` wraps a label to 2 lines at a space (`lbl_split`, `line_center`), clipped to the button; `draw_actions` returns the row height (`act_h`).
- `scm_least_width` = least panel width for the idle labels + Generate; `det_least` (gitview) folds the details panel to its rail under max(200pt, that). Busy labels ("Committing…") do not count, they clip.

Window chrome (`app.s`)
- Settings button toggles (`cmd_toggle_settings`); palette `settings` only opens.
- Narrow window (< `fz(576)` scaled): sidebar hidden until the toggle asks (`side_narrow`, `side_asked`), then at most half the window.
- Sidebar default width = fit (`side_fit_width` = max(`explorer_fit_width`, `explorer_head_width`), 140..600pt, half window). Applied on toggle-show, divider double-click, and launch when the config has no `sidebar_width` (`g_side_w_set`, `app_fit_sidebar`). A fit does not mark settings changed. `side_grow` (rows only) still widens.
- Zen mode: `g_zen`, `cmd_toggle_zen`, Alt+Z. No title bar, sidebar, status bar; `panes_draw` shows only the view with the keys. In editor + terminal context menus, palette, welcome row. Terminal passes the key through (`term_tab_key`). Not persisted.

Tabs and launch
- `TAB_HOME`: welcome page as a tab ("Home", `IC_HOME`), `cmd_home`. `open_initial` -> `app_launch_tab` when nothing was opened or restored: Home, or a terminal if `[editor] home_on_launch = false`. Skipped when headless.
- Closing Home opens a terminal in its place (`app_close_tab` `.Lct_home`). Not recorded for Reopen Closed Tab.
- Closing a terminal with a foreground program asks (`term_busy`: TIOCGPGRP != shell pid; always 0 on Windows). Quit asks once if any terminal is busy (`terms_busy`).
- Last tab closed -> quit (`quit_if_empty`; from `app_close_tab`, `app_close_term`, `unsaved_done`, `cmd_close_all`, `app_close_tab_gone` for `:q!`). Skipped when headless. Explorer delete and project switch do not quit.
- Welcome rows: no Settings/Terminal rows; Zen row added. Zero tabs still draws the welcome page.

Settings and keys
- `[files] hide_dotfiles` (not on Windows): `explorer_excluded` skips dot names (tree + file search).
- `[editor] home_on_launch` (default true).
- Removed bindings: Ctrl+` (toggle terminal), Ctrl+, (settings), Alt+Z for word wrap. Word wrap has no key (Settings / palette). Ctrl+W and Ctrl+F4 close the tab/pane.
- Settings header: one link, "Feedback and issues: GitHub" -> this repo's issues. Website, email, Discord links and their palette commands are gone.

Rebrand
- Everything renamed rhun -> raftaar (binary, files, `RAFTAAR_*` env, config `~/.config/raftaar`, state `~/.local/state/raftaar`, themes, macOS `raftaar.app`). Welcome mark is `IC_RUNE` redrawn from the logo, in its red `#E5262E`.
- URLs point at `Mesum-Hussain/Raftaar` (update check base in `update.s`, installers, docs). Update check default on; there are no releases yet, so it reports nothing.
- `site/` is still rhun's website with the name swapped; `rhun.app` strings remain there. Not published.
- `.github/workflows/pages.yml` and `desktop-launches.yml` are manual-only; `release.yml` still fires on `v*` tags and expects upstream's signing secrets for macOS.

## Test conventions learned the hard way
- Tests that click fixed coordinates pin `sidebar_width = 240` in their config; without it the sidebar fits and the layout moves.
- Headless starts with zero tabs and never auto-quits; real launches differ. The launch tab and quit-on-empty paths have no automated cover.
- `tests/settings-ui.py` builds its rows from `config.s`; a new bool goes in its `BOOLS`. `tests/keys_test.s` checks key hints.
- `tests/data/themes.expected` is name-sorted.
