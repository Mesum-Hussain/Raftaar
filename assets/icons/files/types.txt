# Explorer icons for files without a grammar, and for names that beat their grammar's icon.
# A line lists patterns, then an icon (NAME.svg here) and a color: red orange yellow green blue
# purple pink cyan grey white. A pattern is a whole name or *.ext, matched ignoring case. A whole
# name beats an extension, and this file a grammar's pattern of the same kind. A language's icon is
# the icon key of its grammar in runtime/syntax (icon = rust orange). After a change run
# tools/file-icons.py, then tools/icons.py.
